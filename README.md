# 💻 Sistema de Ventas de Laptops Americanas

## 📌 Descripción del proyecto
El Sistema de Ventas de Laptops Americanas es una página web diseñada para mostrar y gestionar la venta de laptops importadas de Estados Unidos.

El proyecto busca facilitar la visualización de los equipos disponibles, sus características técnicas y sus precios, permitiendo a los clientes conocer los productos antes de realizar una compra.
## Caso de Estudio
Importadora Ita - mi trabajo todo hacemos manualmente escrito y resgistros de venta en hoja
## 🎯 Objetivos

- Mostrar un catálogo de laptops disponibles.
- Presentar las características de cada equipo.
- Mostrar los precios de los productos.
- Facilitar la búsqueda de laptops.
- Ofrecer una experiencia sencilla y amigable para los usuarios.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
